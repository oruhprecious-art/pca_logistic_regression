# PCA Cancer Dataset Analysis

## Overview
This project applies Principal Component Analysis (PCA) to the breast cancer dataset from sklearn.
The dataset is reduced to two principal components to identify essential variables.

## Tools Used
- Python
- scikit-learn
- pandas

## How to Run
1. Install dependencies:
   pip install scikit-learn pandas

2. Run the script:
   python pca_logistic_regression.py

## Bonus
Logistic Regression was used to evaluate predictive performance after PCA.
